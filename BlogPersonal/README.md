# BlogPersonal · Marlon Soto

Web personal de **Marlon Alessandro Soto Rumiche**, estudiante de Ingeniería de Sistemas e Informática (UNS).
Solo HTML, CSS y JavaScript. Sin base de datos. Se publica en Vercel.

## Páginas

| Archivo | Sección |
| --- | --- |
| `index.html` | Inicio, con el recorrido interactivo |
| `sobre-mi.html` | Sobre mí |
| `estudios.html` | Universidad, colegio, certificados, idiomas y habilidades |
| `experiencia.html` | Voluntariado, emprendimiento y prácticas |
| `logros.html` | Pasantía en Cusco y otros logros |
| `proyectos.html` | Esta web y el emprendimiento |
| `galeria.html` | Álbum de fotos |
| `blog.html` y `blog/` | Artículos |
| `contacto.html` | Mensaje de WhatsApp, Instagram y correo |

## Carpetas

- `css/styles.css`: estilos. Los colores de modo claro y oscuro están al inicio (`:root` y `[data-tema="oscuro"]`).
- `js/main.js`: modo oscuro, menú, recorrido, habilidades, álbum y WhatsApp.
- `img/`: fotos (nombres en minúsculas y sin espacios).

## Editar

Busca `EDITAR` en los archivos `.html` para ver los textos que conviene completar con datos reales.

Para cambiar los hitos del recorrido, edita la lista `<ol class="hitos-lista">` en `index.html`.
